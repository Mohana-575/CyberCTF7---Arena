# CyberCTF7 Training Projects

This project is a React + Vite application for the CyberCTF7 training dashboard.

## Commands used

Run these commands from the project root:

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## What each command does

- `npm install` — installs all project dependencies.
- `npm run dev` — starts the Vite development server for local development.
- `npm run build` — creates a production build of the app.
- `npm run preview` — previews the production build locally.
- `npm run lint` — runs the project linter to check code quality.

## Start the app

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
